# Workspace Guidelines: Team-Koseli

## Package Management & CLI Tooling
- **STRICTLY USE PNPM FOR EVERYTHING:** Always use `pnpm` for all package installations, script executions, builds, dev server runs, and tooling across the entire workspace (e.g., `pnpm add <pkg>`, `pnpm install`, `pnpm run dev`, `pnpm run build`, `pnpm dlx`, `pnpm exec`).
- **DO NOT USE `npm`, `npx`, or `yarn`.**
